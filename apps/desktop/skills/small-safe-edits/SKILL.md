# Small safe edits

1. Read the current file before editing.
2. Prefer a targeted patch over rewriting the file.
3. Follow existing names and patterns. Do not add a new framework to make a small change.
4. Leave phone-sync, phone-settings, and official Harness packages untouched unless the user asked to change them.
